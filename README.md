# inw2022-01

Primeira atividade de HTML, com um formulário de cadastro, uma lista de links e uma imagem.

> Atividade desenvolvida na faculdade, em 2022.

## Conteúdo

- Formulário com nome, sobrenome, data de nascimento e endereço
- Lista de links
- Imagem e estilo CSS simples

## Como abrir

Baixe o arquivo `Atividade01.html` e abra no navegador.
